## §1 Task statement (verbatim)

Phase 6 (MVP+) wires the MCP adapter and scratch orchestration engine into the production CLI and API query paths behind an opt-in `--orchestrated` / `orchestrated: true` flag, adds per-step execution trace persistence to the telemetry store beyond the existing aggregate row, and produces a demo shell script and optional asciicast suitable for a portfolio narrative.

T3 specifically delivers item (3): each graph step writes an `agent_executions` row with `agent_name = "orchestration.scratch/{node_name}"`, making per-step durations queryable via `aria telemetry` beyond the single aggregate `orchestration.scratch` row.

**Non-goals:** No new SQLite table or schema change. No changes to the aggregate row behavior. No changes to CLI, API, or demo artifacts (other subtasks own those).

## §2 Shared contracts (verbatim)

### Types / interfaces (T3 scope)

| Symbol | Typed surface | Notes |
|--------|---------------|-------|
| `ORCHESTRATION_SCRATCH_AGENT_NAME` (existing) | `aria/orchestration/scratch/graph.py:29` — `"orchestration.scratch"` | Used as prefix: `f"{ORCHESTRATION_SCRATCH_AGENT_NAME}/{node_name}"` for per-step rows |
| `TelemetryStore.record_agent_execution` (existing) | `aria/observability/telemetry_store.py` — signature: `(*, agent_name: str, status: str, duration_ms: float, request_id: str \| None = None, error: str \| None = None, ts: datetime \| None = None)` | Called once per step, plus existing aggregate call unchanged |

Per-step `agent_name` naming convention: `f"{ORCHESTRATION_SCRATCH_AGENT_NAME}/{step.node_name}"` (slash separator). Example: `"orchestration.scratch/supervisor"`, `"orchestration.scratch/free_query"`, `"orchestration.scratch/end"`.

### Error envelope

No new error codes. Per-step calls wrapped in the same `try/except` pattern as the aggregate call; failures increment `TELEMETRY_WRITE_ERRORS_COUNTER.labels(source="orchestration")` and log a warning (do not raise).

### Naming

No new files. No new symbols beyond the per-step `agent_name` naming convention.

### Tests (T3 policy)

Extend `tests/unit/test_orchestration.py:TestOrchestrationTelemetry`. The mock for `get_telemetry_store()` must now capture all calls. Assertions:
- `record_agent_execution` is called at least N+1 times (N steps + 1 aggregate) for a run with N steps.
- At least one call has `agent_name` matching the pattern `"orchestration.scratch/..."` (i.e. startswith `"orchestration.scratch/"` and has content after the slash).
- The aggregate call with `agent_name="orchestration.scratch"` is still present exactly once.
- Existing assertions on the aggregate call (status, duration_ms) remain; adjust call-count expectations to N+1.
