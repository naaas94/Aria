## §2 Shared contracts (verbatim)

**`INGESTION_DURATION` — existing metric, new observe site:**

```python
INGESTION_DURATION = Histogram(
    "aria_ingestion_duration_seconds",
    "Duration of document ingestion",
    ["format"],
    buckets=[0.1, 0.5, 1.0, 2.5, 5.0, 10.0, 30.0],
)
```

**Label decision (binding — Flag 1 resolved):** Pipeline observe uses `format=fmt.value` where `fmt` is a `DocumentFormat` enum instance. `DocumentFormat.PDF.value == "pdf"`, `DocumentFormat.HTML.value == "html"`. These values are distinct from HTTP smoke route values (`"text"`, `"file"`); no label collision occurs within the Prometheus time series, and no label unification is required.

**Observe call (binding):**
```python
INGESTION_DURATION.labels(format=fmt.value).observe(time.monotonic() - _ingest_start)
```

**Timer scope:**
- `_ingest_start = time.monotonic()` is set immediately **after** the successful `_parse_document` call (i.e., after the `except Exception as exc: return IngestionResult(status=IngestionStatus.PARSE_ERROR, ...)` block at ~line 126).
- Observe fires only at the **final** `return result` (after all pipeline stages: chunking, entity extraction, graph write, vector indexing, Neo4j dedup upsert). This is the single `return result` at the end of the function.
- **Not observed** on early returns: PARSE_ERROR (format detection failure, parse failure) or SKIPPED_DUPLICATE.
