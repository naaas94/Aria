## §2 Shared contracts (verbatim)

**Metric definition (T1 output — must already exist before this subtask executes):**

```python
HTTP_REQUEST_DURATION = Histogram(
    "aria_http_request_duration_seconds",
    "HTTP request latency in seconds",
    ["method", "status_code"],
    buckets=[0.005, 0.01, 0.025, 0.05, 0.1, 0.25, 0.5, 1.0, 2.5, 5.0],
)
```

**Labels:** `method` = `request.method` (string, e.g. `"POST"`), `status_code` = `str(status_code)` (string, e.g. `"200"`). Matches existing `HTTP_REQUEST_COUNTER` labels exactly.

**Observe call (binding):**
```python
HTTP_REQUEST_DURATION.labels(
    method=request.method,
    status_code=str(status_code),
).observe(latency_ms / 1000.0)
```
- Value is in **seconds** (divide `latency_ms` by 1000).
- Placed immediately after `HTTP_REQUEST_COUNTER.labels(...).inc()`, inside the `try` block.
