## §1 Task statement (verbatim)

Phase 3 closes the observability gaps identified in `MVP_PICKUP.md §189–195`. This subtask documents the Ollama `cost_usd=None` behavior for operators in both `README.md` and `.env.example`, so that a `total_cost_usd: 0` value in `GET /telemetry` is understood as expected behavior for local deployments, not a bug.

**Non-goals:**
- No code changes.
- No new env vars invented.
- No changes to `GET /telemetry` JSON shape.
- No changes to `.env.example` structure beyond adding a comment.

## §2 Shared contracts (verbatim)

**Flag 5 resolution (binding):** Both `README.md` AND `.env.example` must receive the documentation. Documenting only one is insufficient.

**Content (binding):**
- The note must explain: LiteLLM returns `response_cost=None` for local providers (Ollama); `aria_llm_cost_usd_total` is not incremented for Ollama calls; `total_cost_usd` in `GET /telemetry` will show `0` for Ollama-only deployments; this is expected.
- The note must NOT imply a bug or a missing feature.

## §4 Subtask spec

**Files to touch:** `README.md`, `.env.example`

**Scope:** Add inline documentation in the appropriate existing sections. Do not create new top-level sections if a suitable existing section is present.

**README.md guidance:**
- Find the LLM configuration or Observability section.
- Add a paragraph or bullet (matching the document's existing style) such as:
  > **Ollama cost tracking:** Ollama (local) providers do not report request cost to LiteLLM. The `aria_llm_cost_usd_total` Prometheus counter and the `total_cost_usd` field in `GET /telemetry` will remain `0` for Ollama-only deployments. This is expected behavior. Cost tracking is active for cloud providers (OpenAI, Anthropic, etc.) that LiteLLM price-lists.
- Place the note near any mention of `LLM_MODEL`, `LLM_BASE_URL`, or cost/telemetry, not in an appendix.

**.env.example guidance:**
- Find the block that documents `LLM_MODEL`, `LLM_BASE_URL`, `LLM_API_KEY`.
- Add a comment immediately below or after those vars:
  ```
  # Ollama (local) does not report request cost to LiteLLM.
  # aria_llm_cost_usd_total will remain 0; total_cost_usd in GET /telemetry will be 0.
  # This is expected for local deployments. Cloud providers (OpenAI, Anthropic) report cost normally.
  ```

**Outputs:** Updated `README.md` and `.env.example`.

**Kill criteria:**
- **HALT** if neither `README.md` nor `.env.example` exists at the repo root — report and stop.
- **HALT** if `LLM_MODEL` / `LLM_BASE_URL` / `LLM_API_KEY` are not present in `.env.example` — do not invent a new section; report the actual structure found.
