## §4 Subtask spec — T3

**Scope:** Change `aria/cli/commands/serve.py` so the `--port` default reads the `API_PORT` environment variable, falling back to `8080` when unset. This resolves the port conflict between Chroma (bound to host port 8000 via `docker-compose.yml`) and `aria serve` (previously also defaulting to 8000).

**Files to touch:**
- `aria/cli/commands/serve.py`

**Contract bindings:** CLI surface: `aria serve --port` default is env-derived (`int(os.getenv("API_PORT", "8080"))`). Types/interfaces: Typer `Option` for `port`.

**Inputs:** None.

**Outputs:**
- Modified `aria/cli/commands/serve.py` where `port` Typer Option uses 8080 (or `API_PORT` env) as default.
- Help text updated: `"Listen port (overridden by API_PORT env var)."` or similar.
- Changelog entry.

**Kill criteria:**
- Halt if Typer's `Option` does not support a callable/dynamic default cleanly (some Typer versions require a literal). In that case: set the Typer `Option` default to the literal `8080` and add an `os.getenv("API_PORT")` override inside the function body, using the env value when set. Either approach satisfies the contract; use whichever is cleaner.

**Log tier:** standard

**Risks & mitigations:**
- Typer CLI `--help` may show `8080` as the literal default (acceptable; `API_PORT` override is documented in help text).
- If using `default_factory`, Typer may display the function name in help. Prefer reading `os.getenv("API_PORT", "8080")` as the default expression directly in the `Option` call if supported, or inside the function body if not.

### Implementation guidance

Current code (confirmed by code inspection):
```python
port: int = typer.Option(8000, "--port", "-p", help="Listen port."),
```

Target: change default from `8000` to `8080`, add env read. Two valid patterns:

**Pattern A** (preferred if Typer supports it):
```python
import os
port: int = typer.Option(
    int(os.getenv("API_PORT", "8080")),
    "--port", "-p",
    help="Listen port (overridden by API_PORT env var).",
),
```

**Pattern B** (fallback — read env in body):
```python
port: int = typer.Option(8080, "--port", "-p", help="Listen port (overridden by API_PORT env var)."),
# Then in the function body:
effective_port = int(os.getenv("API_PORT", str(port)))
uvicorn.run("api.main:app", host=host, port=effective_port, reload=reload)
```

Pattern A evaluates `os.getenv` at module import time; Pattern B evaluates at call time. Pattern B is safer if `API_PORT` might be set after module import.
