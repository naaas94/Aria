## §4 Subtask spec — T4

**Scope:** Modify `aria/cli/commands/ingest.py` to print regulation IDs found in the Neo4j graph immediately after a successful `ingest_document` call. This gives the operator the exact IDs to pass to `aria impact <id>`. Resolves Flag 3 (no documented discovery path for REGULATION_ID_FROM_GRAPH).

**Files to touch:**
- `aria/cli/commands/ingest.py`

**Contract bindings:** Logging contract (`"  regulation_ids: ..."` stdout line). CLI surface (`aria ingest` stdout format extended).

**Inputs:** None (uses the `neo` connection already established in `_ingest_async`).

**Outputs:**
- Modified `aria/cli/commands/ingest.py` with:
  - New private async helper `_fetch_regulation_ids(neo: Neo4jClient) -> list[str]` that executes `MATCH (r:Regulation) RETURN r.id AS id` via `neo.execute_read(...)` and returns a list of ID strings.
  - Call to `_fetch_regulation_ids` after `_print_result(path, result)`, executed when `result.graph_written` is truthy.
  - Output formatted per the Logging contract above.
- Changelog entry.

**Kill criteria:**
- (a) Halt if `Neo4jClient.execute_read` does not accept a plain Cypher string — inspect `aria/graph/client.py` signature before implementing; adapt the call to match the actual API. If `execute_read` requires a different call shape (e.g. accepts a query object, requires parameters dict), adjust accordingly.
- (b) Halt if the Regulation node property key is not `id` — inspect `aria/agents/graph_builder.py` or `aria/contracts/regulation.py` to confirm the property key. Update the Cypher query if the key differs (e.g. `regulation_id`).
- (c) Halt if context-map flag 3 is unresolved at execution start.

**Log tier:** standard

**Risks & mitigations:**
- Entity extractor assigns regulation IDs at LLM runtime; may return zero nodes if extraction didn't produce `Regulation` entities. Mitigation: print the `(none)` warning gracefully; the operator can use `scripts/seed_graph.py` IDs (`reg-gdpr`, `reg-eu-ai-act`) as a fallback for the `aria impact` step.
- `_fetch_regulation_ids` runs inside the `try/finally` block of `_ingest_async` where `neo` is available. Ensure it is called before the `finally: await disconnect_app_dependencies(conns)` cleanup.
- Do NOT call this query when `result.status == SKIPPED_DUPLICATE` (no new write occurred; graph may or may not have Regulation nodes from a prior run). Call it only when `result.graph_written` is True, or always on SUCCESS/SKIPPED_DUPLICATE but only when graph connection is live.

### Implementation guidance

Current flow in `_ingest_async` (confirmed):
```python
result = await ingest_document(
    path,
    entity_extractor=wiring.entity_extractor,
    graph_writer=wiring.graph_writer,
    vector_indexer=wiring.vector_indexer,
    neo4j_dedup=neo,
    force=force,
)
_print_result(path, result)
return _ingestion_exit_code(result)
```

Target insertion point — after `_print_result`, before `return`:
```python
_print_result(path, result)
if result.graph_written:
    reg_ids = await _fetch_regulation_ids(neo)
    if reg_ids:
        print(f"  regulation_ids: {', '.join(reg_ids)}")
    else:
        print(
            "  regulation_ids: (none — Regulation nodes not found; "
            "use seed_graph.py IDs or check entity extractor)"
        )
return _ingestion_exit_code(result)
```

For `_fetch_regulation_ids`, inspect `aria/graph/client.py` for the `execute_read` signature. A plausible shape:
```python
async def _fetch_regulation_ids(neo: "Neo4jClient") -> list[str]:
    records = await neo.execute_read("MATCH (r:Regulation) RETURN r.id AS id")
    return [r["id"] for r in records if r.get("id")]
```
Adjust the Cypher property name and record access pattern to match the actual client API.
