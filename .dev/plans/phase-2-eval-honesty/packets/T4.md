## Execution guidance

### Step 1 — Verify run_replay_check dispatch

Read `tests/eval/golden_set/test_goldens.py`. Confirm the lens dispatch block calls `run_replay_check(case)` when `case.expect.replay is not None`. If the dispatch guard is different, adjust the YAML accordingly or HALT if the code path is unreachable.

### Step 2 — Confirm ReplayFixture field names

Read `tests/eval/golden_set/recorder.py`. Confirm `ReplayFixture` dataclass has exactly these fields (in any order):
```
case_id, correlation_id, recorded_at, aria_commit, request, response, strategy_used
```
Confirm `load_replay_fixture` does `ReplayFixture(**raw)` (positional or keyword unpack from JSON dict). The JSON file must contain all these keys at the top level.

### Step 3 — Confirm run_replay_check response access pattern

Read `tests/eval/golden_set/runner.py:run_replay_check`. The `fixture.response` dict is accessed as:
- `resp.get("answer")` — must be a non-empty string
- `resp.get("retrieval_strategy", fixture.strategy_used)` — compared to `spec.expected_strategy`
- `resp.get("sources", [])` — must have length ≥ `spec.min_source_count`
- `resp.get("trace", {})` — `spec.required_trace_keys` are checked for presence in this dict
- If `spec.quality` is set, `resp.get("answer", "")` and `resp.get("sources", [])` are used for quality sub-checks

The quality sub-check builds a temporary `GoldenCase` with `input={"answer": resp["answer"], "sources": sources}` and runs `run_quality_check`. The `must_mention` list is checked against `answer.lower()`.

### Step 4 — Author the new YAML case

Create `tests/eval/golden_set/cases/retrieval/q6_replay_gdpr_erasure.yaml`:

```yaml
id: eval-replay-gdpr-erasure
category: happy
tier: slow
tags: [replay, gdpr, erasure]
description: >
  Slow-tier replay regression for GDPR right-to-erasure query. Validates
  run_replay_check against a committed hand-authored fixture without live
  infrastructure. Runs in nightly (--golden-tier=slow); skipped in PR fast tier.
input:
  question: "What is the right to erasure under GDPR and how must organizations comply?"
expect:
  replay:
    fixture_file: eval-replay-gdpr-erasure.json
    expected_strategy: hybrid
    min_source_count: 2
    required_trace_keys:
      - nodes_retrieved
      - strategy
    quality:
      must_mention:
        - erasure
        - personal data
      min_source_count: 2
```
